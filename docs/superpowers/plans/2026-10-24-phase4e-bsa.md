> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A ferramenta **BSA Packer** (plugin `bsapacker` do upstream) cria BSA/BA2 no Linux, sobre o `libbsarchpp` 1.0.7, com o Windows inalterado (spec §1).

**Architecture:** O `libbsarchpp` (C++23) é baixado numa tag fixa e compilado estático por `build/libbsarchpp/build-libbsarchpp.sh`, que também instala o cabeçalho `boost/di.hpp`. Os fontes do upstream só ganham um `#ifdef _WIN32` no DDS e o CMake em `if (WIN32)`/`else()`.

**Tech Stack:** C++23 (GCC 16), Qt 6 (Core, Widgets, Concurrent), CMake + Ninja, `cmake_common` (`mo2_configure_plugin`, `mo2_configure_tests`), GoogleTest/gmock, `libbsarchpp` 1.0.7 (zlib, lz4, TBB, gsl-lite), `boost-ext/di` 1.3.2, `bsatk` (leitor independente nos testes), bash.

- [ ] **Step 4: `build/libbsarchpp/build-libbsarchpp.sh`** (`chmod +x`)

```bash
#!/usr/bin/env bash
# Build libbsarchpp 1.0.7 (Kaedras/libbsarchpp, a C++ reimplementation of xEdit's
# BSArchive) as a static, position-independent library with its headers and CMake
# package into <root>/install, and install the boost-ext/di header (boost/di.hpp) that
# bsapacker needs; Fedora packages neither (spec of Phase 4e, section 2). The bsapacker
# plugin links libbsarchpp on Linux in place of libbsarch, which is Windows-only.
#
#   build/libbsarchpp/build-libbsarchpp.sh
#
# Environment (all optional):
#   INSTALL    install prefix            (default <root>/install)
#   BUILD_OUT  build tree root           (default <root>/build-out)
#   TESTS      1: build and run the tests of libbsarchpp that need no game data
#
# Everything it fetches and builds stays in $BUILD_OUT/libbsarchpp.
#
# Produces:
#   $INSTALL/lib/libbsarchpp.a, $INSTALL/include/libbsarchpp/*.h
#   $INSTALL/lib/cmake/libbsarchpp/   (find_package(libbsarchpp CONFIG), target libbsarchpp)
#   $INSTALL/include/boost/di.hpp
set -euo pipefail

HERE="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT="$(cd "$HERE/../.." && pwd)"
INSTALL="${INSTALL:-$ROOT/install}"
BUILD_OUT="${BUILD_OUT:-$ROOT/build-out}"
TESTS="${TESTS:-0}"

LIBBSARCHPP_REPO="https://github.com/Kaedras/libbsarchpp"
LIBBSARCHPP_TAG="1.0.7"
# Commit the tag must resolve to (the tag is moveable, the commit is not).
LIBBSARCHPP_COMMIT="211a681cf89310af5c3f824315ba03eb64651a95"
DI_REPO="https://github.com/boost-ext/di"
DI_TAG="v1.3.2"
DI_COMMIT="20b6454c889f23c1e7c9eb5136cd7e3d6f6d718d"

WORK="$BUILD_OUT/libbsarchpp"
SRC="$WORK/src"
DI_SRC="$WORK/di"
OBJ="$WORK/build"

log() { echo "==> libbsarchpp: $*"; }
die() { echo "build-libbsarchpp.sh: $*" >&2; exit 1; }

# fetch <repo> <tag> <commit> <dir>: shallow clone of the tag, verified by commit hash
# (cached; safe.directory as in build/libloot/build-libloot.sh)
head_of() { git -c safe.directory="$1" -C "$1" rev-parse HEAD 2>/dev/null || true; }
fetch() {
    local repo="$1" tag="$2" commit="$3" dir="$4"
    if [[ $(head_of "$dir") != "$commit" ]]; then
        log "fetching $repo @ $tag"
        rm -rf "$dir"
        mkdir -p "$WORK"
        git clone --quiet --depth 1 --branch "$tag" -c advice.detachedHead=false "$repo" "$dir"
        [[ $(head_of "$dir") == "$commit" ]] ||
            die "tag $tag of $repo resolved to $(head_of "$dir"), expected $commit"
        rm -rf "$OBJ"
    fi
}
fetch "$LIBBSARCHPP_REPO" "$LIBBSARCHPP_TAG" "$LIBBSARCHPP_COMMIT" "$SRC"
fetch "$DI_REPO" "$DI_TAG" "$DI_COMMIT" "$DI_SRC"
log "source at $LIBBSARCHPP_COMMIT, boost-ext/di at $DI_COMMIT"

# our package config (see config.cmake.in); restored from git on every run so that
# the source tree stays the fetched one
git -c safe.directory="$SRC" -C "$SRC" checkout --quiet -- cmake/config.cmake.in
install -m 0644 "$HERE/config.cmake.in" "$SRC/cmake/config.cmake.in"

# --- build ------------------------------------------------------------------
testing=OFF
[[ $TESTS == 1 ]] && testing=ON
games=()
for g in TES3 TES4 TES5 SSE SKYRIMVR FO3 FONV FO4 FO4VR SF; do
    games+=("-DTESTS_${g}_ENABLE=OFF")
done
log "configure"
cmake -S "$SRC" -B "$OBJ" -G Ninja \
    -DCMAKE_BUILD_TYPE=RelWithDebInfo \
    -DCMAKE_INSTALL_PREFIX="$INSTALL" \
    -DCMAKE_INSTALL_LIBDIR=lib \
    -DBUILD_SHARED_LIBS=OFF \
    -DCMAKE_POSITION_INDEPENDENT_CODE=ON \
    -DLIBBSARCHPP_TESTING="$testing" \
    -DTESTS_WORKDIR="$WORK/testwork" \
    "${games[@]}"
log "build"
cmake --build "$OBJ"
if [[ $TESTS == 1 ]]; then
    # the suites per game need the games' archives (/opt/archives) and are off; what is
    # left needs no game data (Misc, Hash, GSL, CreateArchive)
    mkdir -p "$WORK/testwork"
    log "test"
    ctest --test-dir "$OBJ" --output-on-failure
fi
log "install into $INSTALL"
cmake --install "$OBJ"
install -Dm 0644 "$DI_SRC/include/boost/di.hpp" "$INSTALL/include/boost/di.hpp"

# --- check ------------------------------------------------------------------
[[ -f $INSTALL/lib/libbsarchpp.a ]] || die "libbsarchpp.a was not installed"
compgen -G "$INSTALL/lib/cmake/libbsarchpp/*onfig.cmake" >/dev/null ||
    die "the CMake package of libbsarchpp was not installed"
if [[ $TESTS == 1 ]]; then
    # the installed package, on its own: found, linked into a shared object, and the
    # archive it writes reads back
    log "consumer check"
    rm -rf "$WORK/consumer" "$WORK/consumer-run"
    cmake -S "$HERE/consumer" -B "$WORK/consumer" -G Ninja \
        -DCMAKE_BUILD_TYPE=RelWithDebInfo -DCMAKE_PREFIX_PATH="$INSTALL"
    cmake --build "$WORK/consumer"
    mkdir -p "$WORK/consumer-run"
    out="$("$WORK/consumer/consumer" "$WORK/consumer-run")" || die "consumer check failed: $out"
    [[ $out == ok ]] || die "consumer printed '$out', expected 'ok'"
    rm -rf "$WORK/consumer-run"
    log "consumer check: ok"
fi
log "installed $INSTALL/lib/libbsarchpp.a"
```

```cpp
// Tests of the Linux bs_archive_auto (deps/bsapacker/linux, spec of Phase 4e, sections
// 3.2 and 5.3): archives written through the libbsarch-compatible API read back with
// libbsarchpp and, where it reads the format, with bsatk.

#include <libbsarchpp/Bsa.h>

#include <algorithm>
#include <cctype>
#include <cstdlib>
#include <filesystem>
#include <fstream>

namespace fs = std::filesystem;

namespace
{

class TempDir
{
public:
  TempDir()
  {
    std::string tmpl = (fs::temp_directory_path() / "bsapacker-tests-XXXXXX").string();
    if (mkdtemp(tmpl.data()) == nullptr) {
      throw std::runtime_error("mkdtemp failed");
    }
    m_path = tmpl;
  }
  ~TempDir()
  {
    std::error_code ec;
    fs::permissions(m_path, fs::perms::owner_all, fs::perm_options::add, ec);
    fs::remove_all(m_path, ec);
  }
  const fs::path& path() const { return m_path; }

private:
  fs::path m_path;
};

void writeFile(const fs::path& path, const std::string& content)
{
  fs::create_directories(path.parent_path());
  std::ofstream(path, std::ios::binary) << content;
}

std::string readFile(const fs::path& path)
{
  std::ifstream in(path, std::ios::binary);
  return {std::istreambuf_iterator<char>(in), {}};
}

// lower case, '/' separators: archives store names in their own case and separator
std::string normalized(std::string path)
{
  std::replace(path.begin(), path.end(), '\\', '/');
  std::transform(path.begin(), path.end(), path.begin(), [](unsigned char c) {
    return static_cast<char>(std::tolower(c));
  });
  return path;
}

// relative path -> content of the files of a mod folder
std::map<std::string, std::string> looseFiles(const fs::path& root)
{
  std::map<std::string, std::string> files;
  for (const auto& entry : fs::recursive_directory_iterator(root)) {
    if (entry.is_regular_file()) {
      files[normalized(fs::relative(entry.path(), root).generic_string())] =
          readFile(entry.path());
    }
  }
  return files;
}

// a mod folder whose path has spaces, with mixed-case folders and a compressible file
fs::path makeMod(const fs::path& base)
{
  const fs::path root = base / "mods" / "My Test Mod";
  writeFile(root / "Meshes" / "Armor" / "Cuirass.nif", std::string(8192, 'n'));
  writeFile(root / "scripts" / "test.pex", "pex data");
  return root;
}

// packs every file of root with the libbsarch-compatible API, as the builders do
void pack(const fs::path& root, bsa_archive_type_t type, bool compressed,
          const fs::path& archive)
{
  libbsarch::bs_archive_auto bsa(type);
  const std::wstring rootString = (root.wstring() + L'/');
  for (const auto& entry : fs::recursive_directory_iterator(root)) {
    if (entry.is_regular_file()) {
      bsa.add_file_from_disk(libbsarch::disk_blob(rootString, entry.path().wstring()));
    }
  }
  bsa.set_compressed(compressed);
  bsa.set_dds_callback(nullptr, rootString);
  bsa.save_to_disk(archive);
}

// relative path -> content, as libbsarchpp reads the archive back
std::map<std::string, std::string> readWithLibbsarchpp(const fs::path& archive)
{
  libbsarchpp::Bsa bsa(archive);
  std::map<std::string, std::string> files;
  for (const auto& name : bsa.getFileList()) {
    const auto data = bsa.extractFileData(name);
    files[normalized(name.generic_string())] = std::string(data.begin(), data.end());
  }
  return files;
}
```

```cpp
#include <libbsarch/bs_archive_auto.hpp>

#include <libbsarchpp/Bsa.h>
#include <libbsarchpp/enums.h>

#include <QDebug>
#include <QString>

#include <optional>
#include <stdexcept>
#include <system_error>

namespace fs = std::filesystem;

namespace libbsarch
{

namespace
{
  // UTF-8, whatever the locale (std::filesystem::path(std::wstring) converts with it)
  fs::path utf8Path(const std::wstring& path)
  {
    return fs::path(QString::fromStdWString(path).toStdString());
  }

  // the part of absolute after root, as libbsarchpp's Bsa::addFile strips it
  fs::path inArchive(const fs::path& root, const fs::path& absolute)
  {
    const std::string rootString = root.generic_string();
    std::size_t pos              = rootString.length();
    if (pos > 1 && !rootString.ends_with('/')) {
      ++pos;
    }
    return fs::path(absolute.generic_string().substr(pos));
  }

  libbsarchpp::ArchiveType toLibbsarchpp(bsa_archive_type_t type)
  {
    switch (type) {
    case baTES3:
      return libbsarchpp::TES3;
    case baTES4:
      return libbsarchpp::TES4;
    case baFO3:
      return libbsarchpp::FO3;
    case baSSE:
      return libbsarchpp::SSE;
    case baFO4:
      return libbsarchpp::FO4;
    case baFO4dds:
      return libbsarchpp::FO4dds;
    case baSF:
      return libbsarchpp::SF;
    case baSFdds:
      return libbsarchpp::SFdds;
    case baNone:
    default:
      throw std::runtime_error("no archive type");
    }
  }
}  // namespace

disk_blob::disk_blob(const std::wstring& root, const std::wstring& absolute)
    : disk_blob(utf8Path(root), utf8Path(absolute))
{}

disk_blob::disk_blob(const fs::path& root, const fs::path& absolute)
    : root_dir(root), path_on_disk(absolute), path_in_archive(inArchive(root, absolute))
{}

bs_archive_auto::bs_archive_auto(const bsa_archive_type_t& type) : m_type(type) {}

void bs_archive_auto::add_file_from_disk(const disk_blob& blob)
{
  m_files.push_back(blob);
}

void bs_archive_auto::set_compressed(bool value)
{
  m_compressed = value;
}

void bs_archive_auto::set_share_data(bool value)
{
  m_shareData = value;
}

void bs_archive_auto::set_dds_callback(bsa_file_dds_info_proc_t, const std::wstring& root)
{
  m_ddsRoot = utf8Path(root);
}

void bs_archive_auto::save_to_disk(const fs::path& archive_path)
{
  try {
    if (m_files.empty()) {
      throw std::runtime_error("no files to pack");
    }

    std::vector<fs::path> fileList;
    fileList.reserve(m_files.size());
    for (const auto& file : m_files) {
      fileList.push_back(file.path_in_archive);
    }

    const std::optional<fs::path> ddsBasePath =
        m_ddsRoot.empty() ? std::nullopt : std::optional<fs::path>(m_ddsRoot);

    // the full constructor: the 4-argument one of libbsarchpp 1.0.7 leaves the object
    // uninitialized (spec of Phase 4e, section 1.3); one thread, for a deterministic
    // archive
    libbsarchpp::Bsa bsa(archive_path, toLibbsarchpp(m_type), fileList, ddsBasePath,
                         m_compressed, m_shareData, false);
    for (const auto& file : m_files) {
      bsa.addFile(file.root_dir, file.path_on_disk);
    }
    bsa.save();
  } catch (const std::exception& e) {
    qWarning().noquote() << QString("failed to write archive %1: %2")
                                .arg(QString::fromStdString(archive_path.string()))
                                .arg(QString::fromStdString(e.what()));
    std::error_code ec;
    fs::remove(archive_path, ec);
    throw;
  }
}

}  // namespace libbsarch
```

> **Criação de BSA/BA2:** **Ferramentas → BSA Packer** empacota os arquivos soltos de um mod num `.bsa` (Morrowind, Oblivion, Fallout 3/NV, Skyrim, Skyrim SE) ou `.ba2` (Fallout 4 e Starfield, com as texturas num `… - Textures.ba2` à parte) na pasta do mod. Em **Configurações → Plugins → BSA Packer**: "create_plugins" cria o plugin vazio (`.esp`/`.esl`) que faz o jogo carregar o arquivo; "hide_loose_assets" esconde os arquivos soltos (as pastas viram `….mohidden`); "blacklisted_files" lista as extensões que ficam de fora; "compress_archives" comprime. No Linux o arquivo é escrito pelo `libbsarchpp` (no Windows, pelo `libbsarch`); o resultado é o mesmo formato, mas os arquivos LZ4 (Skyrim SE, Starfield) não são idênticos byte a byte aos do xEdit. Validado no Skyrim SE; os demais jogos são suportados, não validados. Um único arquivo acima de 4 GiB não é criado (o motivo vai para o log).

Na lista de pacotes do box (se o README listar pacotes de execução), acrescentar `tbb` (o `libbsa_packer.so` usa o `libtbb`; o `tbb-devel` do build já o instala).

```markdown
Linux patches (all in `deps/bsapacker`, spec of Phase 4e, section 3):
```
